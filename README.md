# Generative AI 🚀

A comprehensive repository documenting my learning, implementations, and hands-on projects in **Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and Agentic AI**.

This repository contains practical implementations, experiments, notes, and projects developed while exploring modern Generative AI technologies.

## 🎯 Repository Objectives

- Understand the fundamentals of Generative AI and Large Language Models.
- Explore prompt engineering and effective prompting techniques.
- Work with LLM APIs and open-source language models.
- Build Retrieval-Augmented Generation (RAG) applications.
- Implement vector databases and semantic search.
- Develop AI-powered applications using Python.
- Explore AI agents and agentic workflows.
- Understand model evaluation, hallucinations, and responsible AI.

## 📚 Topics Covered

| Topic | Description |
|---|---|
| Generative AI | Fundamentals, architecture, and applications |
| LLMs | Large Language Models and their capabilities |
| Prompt Engineering | Zero-shot, few-shot, and structured prompting |
| Tokens & Context Windows | Tokenization, context limits, and model inputs |
| Embeddings | Semantic representations of text |
| Vector Databases | FAISS and similarity search |
| RAG | Document retrieval and context-grounded generation |
| LLM APIs | Integrating AI models into Python applications |
| Open-Source LLMs | Exploring Hugging Face and Ollama |
| AI Agents | Tool calling, reasoning, and agentic workflows |
| Model Evaluation | Response quality, accuracy, and hallucination analysis |
